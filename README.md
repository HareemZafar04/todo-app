# Hackathon II – Evolution of Todo  
## Phase I: In-Memory Python Console Application

This repository contains **Phase I** of **Hackathon II – Evolution of Todo** project.  
The project is built strictly using **Spec-Driven Development (SDD)** methodology.

Phase I focuses on implementing a **basic, single-user todo application**
that runs in the terminal and stores all data **in memory only**.

---

## 🚀 Hackathon Phase
**Phase I – Core Todo (Basic Level)**

Status: ✅ **Completed**  
Scope: Locked and finalized as per SDD rules

---

## 🎯 Phase I Objectives
- Build a simple console-based todo application
- Follow the complete SDD lifecycle:
  **Constitution → Specify → Plan → Tasks → Implement**
- No manual coding
- No future-phase features

---

## 🧩 Features Implemented (Basic Level Only)
1. Add Task  
2. View Task List  
3. Update Task  
4. Delete Task  
5. Mark Task Complete / Incomplete  

---

## 🧠 Technical Constraints (Phase I)
- Single user
- In-memory data storage
- Console / CLI based interaction
- No persistence beyond runtime

❌ No database  
❌ No file storage  
❌ No authentication  
❌ No web or API  
❌ No AI or cloud components  

---

## 🛠 Tech Stack
- **Python 3.13+**
- Command Line Interface (CLI)
- In-memory data structures
- `uv` for virtual environment management (optional)
